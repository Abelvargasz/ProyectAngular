🔒 Protocolos de Seguridad en Sistemas Web

Los protocolos de seguridad son un conjunto de reglas y mecanismos diseñados para proteger la información y las comunicaciones dentro de una red o aplicación. Su objetivo es garantizar la confidencialidad, integridad y disponibilidad de los datos frente a accesos no autorizados o ataques informáticos.

🌐 Principales Protocolos de Seguridad

HTTPS (HyperText Transfer Protocol Secure):
Cifra la comunicación entre el navegador y el servidor mediante SSL/TLS, evitando que los datos (como contraseñas o información personal) sean interceptados.

SSL/TLS (Secure Socket Layer / Transport Layer Security):
Protocolo que establece una conexión segura y encriptada entre dos dispositivos. Es la base de la seguridad en la web moderna.

SSH (Secure Shell):
Permite acceder de forma segura a servidores remotos mediante autenticación y cifrado, común en la administración de sistemas y despliegue de aplicaciones.

SFTP (Secure File Transfer Protocol):
Variante segura del FTP que cifra tanto los datos transferidos como las credenciales de acceso.

OAuth 2.0:
Protocolo de autenticación y autorización que permite a los usuarios acceder a servicios sin compartir sus credenciales directamente (por ejemplo, al iniciar sesión con Google o Facebook).

JWT (JSON Web Token):
Mecanismo usado en aplicaciones modernas (como las hechas en Spring Boot o Angular) para mantener sesiones seguras y validar la identidad del usuario mediante tokens firmados.
